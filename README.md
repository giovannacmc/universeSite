# UniverseSite — Observatório Aurora

Projeto desenvolvido para a Avaliação Final da disciplina de Linguagens de Programação.

O **Observatório Aurora** é um site com tema de astronomia, criado para apresentar conteúdos sobre o universo, planetas, galáxias, nebulosas e curiosidades astronômicas de forma visual, organizada e responsiva.

## Páginas do site

### Home

A página inicial apresenta o tema principal do projeto, com uma introdução sobre astronomia e exploração do universo. Ela conta com menu de navegação, carrossel de imagens e seções informativas sobre o espaço.

### Galeria

A página de galeria reúne imagens relacionadas ao universo, como planetas, galáxias, nebulosas, telescópios e outros elementos astronômicos. As imagens são exibidas em cards organizados, deixando o site mais visual e atrativo.

### Contato

A página de contato possui um formulário para o usuário preencher informações como nome, e-mail, telefone, assunto e mensagem. O formulário conta com validação em JavaScript e exibe uma mensagem de sucesso após o envio.

## Como executar o projeto

1. Baixe ou clone este repositório:

git clone https://github.com/giovannacmc/universeSite.git

2. Acesse a pasta do projeto:

cd universeSite

3. Abra o arquivo `index.html` no navegador.

Também é possível executar o projeto usando a extensão **Live Server** no Visual Studio Code.

## Objetivo do projeto

O objetivo deste projeto é aplicar os conhecimentos adquiridos em HTML, CSS, JavaScript e Bootstrap na criação de um site completo, responsivo e interativo.

O site foi desenvolvido com foco em organização de páginas, estilização personalizada, uso de imagens, responsividade e funcionalidades básicas de interação com o usuário.

## Sobre o desenvolvimento

Durante o desenvolvimento do projeto, foram utilizadas páginas separadas para organizar melhor o conteúdo. O HTML foi usado para estruturar as páginas, o CSS para personalizar o visual do site e o JavaScript para adicionar interatividade, como a validação do formulário, o botão de voltar ao topo e a troca entre tema claro e escuro.

O Bootstrap foi utilizado para auxiliar na responsividade e na organização dos elementos da página, facilitando a adaptação do site para diferentes tamanhos de tela.
